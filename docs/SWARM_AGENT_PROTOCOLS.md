## 2. Deliberation & Consensus Formation
When a critical border incident or anomalous activity is detected:
1. **Parallel Ingestion**: All 5 agents simultaneously analyze the telemetry payload with zero cross-blocking.
2. **Confidence Matrix Generation**: Each agent produces an independent perspective and confidence score.
3. **Consensus Aggregation**: The orchestrator aggregates votes with weighted authority scoring.
4. **Countermeasure Synthesis**: Once consensus passes the 90% threshold, automated countermeasures (e.g. siren activation, zone illumination, QRF dispatch) are staged for operator confirmation.
